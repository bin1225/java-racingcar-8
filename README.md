# java-racingcar-precourse

## 자동차 경주

초간단 자동차 경주 게임

## 주요 기능

### 입력

사용자로부터 경주할 자동차 이름을 입력받는다.

- 이름은 쉼표(,) 기준으로 구분한다.
- 이름은 5자 이하만 가능하다.
- 입력받은 이름의 개수만큼 자동차를 등록한다.

사용자로부터 몇 번의 이동을 할 것인지를 입력받는다.

- 입력은 1이상 정수만 가능하다.

### 실행

주어진 횟수 동안 n대의 자동차는 전진하거나 멈춘다.

- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.

### 실행 결과

전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.

자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다.

- 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.

### 예외 처리
사용자가 잘못된 값을 입력할 경우`IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료된다.

## 구현할 기능 목록

### 자동차 이름 입력 및 검증
- 사용자로부터 자동차 이름 문자열 입력받기 (쉼표(,) 기준 분리)
- 이름 유효성 검증
  - 이름이 5자 초과일 경우 IllegalArgumentException 발생
  - 중복된 이름일 경우 예외 발생 (선택 사항)
  - 공백 또는 빈 문자열일 경우 예외 발생

### 시도 횟수 입력 및 검증
- 사용자로부터 시도 횟수 입력받기
  - 정수로 변환 가능한지 검증
  - 0 이하 값 입력 시 예외 발생

### 자동차 등록
- 입력받은 이름 리스트를 기반으로 자동차 등록
- 각 자동차의 초기 위치를 0으로 설정

### 자동차 이동 로직
- Random값을 추출하여 threshold 이상일 경우 자동차 위치 1 증가
- 그렇지 않으면 위치 유지

### 경주 실행
- 사용자가 입력한 시도 횟수만큼 반복 수행
- 각 라운드마다 모든 자동차 이동 후 진행 상태 출력
- 모든 라운드 완료 후 우승자 계산 및 결과 출력
### 우승자 판별
- 모든 참가자의 position 중 최댓값 계산
- 최댓값과 동일한 position을 가진 자동차를 우승자로 선정

### 진행 상황 및 결과 출력
- 현재 진행 상황 출력
- 최종 우승자 출력

### 입력값 예외 처리
-  모든 입력 검증 실패 시 IllegalArgumentException 발생 후 프로그램 종료
